# Chapitre 8 : Gestion des Listes et Qualité des Données

## 8.1 La Qualité des Données est Cruciale

Une liste de mauvaise qualité = temps perdu + frustration + taux de conversion bas. Une liste propre = appels efficaces + prospects qualifiés + résultats.

**Règle** : Mieux vaut 100 contacts qualifiés que 1000 contacts aléatoires.

## 8.2 Les Critères d'une Bonne Liste

| Critère | Description |
|---------|-------------|
| **Nom valide** | Nom et prénom corrects |
| **Numéro valide** | Numéro de téléphone existant et à jour |
| **Rôle pertinent** | La personne peut décider ou influencer |
| **Entreprise cible** | Match avec votre ICP |
| **Secteur** | Votre secteur cible |
| **Taille** | Votre fourchette de taille |
| **Signal** | Raison d'appeler (recrutement, croissance, etc.) |

## 8.3 Construire une Liste

**Sources de données :**
- **LinkedIn Sales Navigator** : Filtres précis (secteur, taille, rôle)
- **Sites d'entreprise** : Informations sur l'organisation
- **Job postings** : Signaux de croissance
- **Annuaire sectoriels** : Listes par industrie
- **Salons et événements** : Contacts qualifiés
- **Referrals** : Clients existants
- **AgentBridge** : Génération et enrichissement de listes

## 8.4 Nettoyer une Liste

**Avant d'appeler, nettoyez :**
- [ ] Dédupliquer (pas de doublons)
- [ ] Vérifier les numéros (pas de numéros invalides)
- [ ] Vérifier les emails (pas de bounce)
- [ ] Vérifier la pertinence (ICP match)
- [ ] Retirer les "Do Not Call"
- [ ] Enrichir (ajouter infos manquantes)

## 8.5 Segmenter une Liste

**Segmentation pour AgentBridge :**

| Segment | Critères | Priorité |
|---------|----------|----------|
| **Tier 1** | ICP parfait + signal fort | Haute |
| **Tier 2** | ICP bon + signal moyen | Moyenne |
| **Tier 3** | ICP approximatif | Basse |

**Règle** : 70% du temps sur Tier 1, 20% sur Tier 2, 10% sur Tier 3.

## 8.6 L'Enrichissement de Données

**Enrichir = ajouter de la valeur à chaque contact :**
- Poste exact
- Ancienneté
- Signaux récents (LinkedIn activity)
- Technologie utilisée
- Concurrents
- Défis connus
- Décideurs associés

🤖 **AgentBridge pour l'enrichissement** : AgentBridge peut générer un résumé enrichi pour chaque prospect automatiquement.

## 8.7 La Rotation des Listes

**Ne pas appeler la même liste en boucle :**
- **Semaine 1** : Tier 1 (nouveaux)
- **Semaine 2** : Tier 1 (relance) + Tier 2 (nouveaux)
- **Semaine 3** : Tier 2 (relance) + Tier 3 (nouveaux)
- **Semaine 4** : Refresh + nouveaux signaux

## 8.8 Les Indicateurs de Qualité

| Indicateur | Bon | Mauvais |
|-----------|-----|---------|
| **Taux de décroché** | >30% | <15% |
| **Taux de bonne personne** | >50% | <20% |
| **Taux de pertinence** | >70% | <40% |
| **Taux de bounce** | <5% | >15% |

Si vos indicateurs sont mauvais, le problème est la liste, pas votre script.
