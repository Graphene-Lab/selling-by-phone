# Chapitre 63 : Checklists pour la Vente Téléphonique

## 63.1 Checklist Pré-Appel

**Avant chaque appel (5 minutes) :**
- [ ] Revoir le record CRM du prospect
- [ ] Vérifier les emails récents (réponses, contexte)
- [ ] Recherche rapide sur LinkedIn/entreprise (si nouveau)
- [ ] Identifier votre objectif (North Star)
- [ ] Préparer 3 questions clés
- [ ] Préparer la fermeture (prochain pas)
- [ ] Vérifier l'environnement (silence, écouteurs, connexion)
- [ ] Respirer, sourire, énergie haute
- [ ] Garder AgentBridge ouvert pour les notes
- [ ] Timer réglé (si nécessaire)

## 63.2 Checklist Pendant l'Appel

**Pendant chaque appel :**
- [ ] Ouverture avec pattern interrupt
- [ ] Nom complet + entreprise
- [ ] Motif spécifique de l'appel
- [ ] Permission de procéder
- [ ] Questions de découverte (ouvertes)
- [ ] Écoute active (silence, paraphrase)
- [ ] Prendre des notes (AgentBridge)
- [ ] Relier la valeur à leur problème
- [ ] Gérer les objections (LAER)
- [ ] Clôturer avec un prochain pas spécifique
- [ ] Confirmer date/heure
- [ ] Remercier

## 63.3 Checklist Post-Appel

**Dans l'heure après l'appel :**
- [ ] Mettre à jour le CRM avec notes détaillées
- [ ] Envoyer un email de follow-up (si convenu)
- [ ] Planifier le prochain pas au calendrier
- [ ] Mettre à jour la pipeline/phase
- [ ] Documenter les objections soulevées
- [ ] Sauvegarder les citations exactes
- [ ] Auto-évaluation (ce qui a fonctionné, ce qui n'a pas fonctionné)
- [ ] Si rendez-vous fixé : envoyer confirmation + rappel

## 63.4 Checklist Cold Call

**Spécifique pour le cold call :**
- [ ] Liste vérifiée (numéro valide)
- [ ] Timing correct (9h-11h ou 14h-16h)
- [ ] Recherche pré-call faite (au moins 2 min)
- [ ] Ouverture personnalisée préparée
- [ ] Motif spécifique identifié
- [ ] Objectif clair (rendez-vous, pas vente)
- [ ] Script de gestion de refus prêt
- [ ] Script de voicemail prêt (s'ils ne répondent pas)
- [ ] Follow-up planifié (si ne convertit pas)

## 63.5 Checklist Démo Téléphonique

**Pour une démo efficace :**
- [ ] Démo personnalisée préparée (avec leurs données)
- [ ] AgentBridge testé et fonctionnel
- [ ] Backup prêt (screenshots, vidéo)
- [ ] Agenda envoyé 24h avant
- [ ] Participants confirmés
- [ ] Durée définie (15-30 min)
- [ ] 3 points clés préparés
- [ ] Questions de check-in planifiées
- [ ] Fermeture préparée (prochain pas)
- [ ] Matériaux prêts à envoyer post-démo

## 63.6 Checklist Follow-Up

**Pour un follow-up efficace :**
- [ ] Dans les 24 heures de l'appel précédent
- [ ] Valeur ajoutée (pas juste "je voulais vérifier")
- [ ] Référence à la conversation précédente
- [ ] Prochain pas clair
- [ ] Date/heure spécifique proposée
- [ ] Email de support envoyé
- [ ] CRM mis à jour
- [ ] Si pas de réponse : planifier 2e et 3e follow-up

## 63.7 Checklist Pipeline Review

**Hebdomadaire :**
- [ ] Chaque deal a un prochain pas
- [ ] Chaque deal a une date de clôture
- [ ] Aucun deal stagnant (>30 jours sans mouvement)
- [ ] Pipeline coverage >3x target
- [ ] Forecast mis à jour
- [ ] Deals à risque identifiés
- [ ] Priorités de la semaine définies
- [ ] Support nécessaire identifié

## 63.8 Checklist Onboarding Client

**Premier appel post-vente :**
- [ ] Bienvenue chaleureuse
- [ ] Objectifs du client clarifiés
- [ ] Setup guidé (pas à pas)
- [ ] Quick win obtenu
- [ ] Contacts de support clairs
- [ ] Plan des 4 premières semaines
- [ ] Prochain check-in fixé
- [ ] Matériaux de support envoyés
- [ ] NPS initial collecté

## 63.9 Checklist Renouvellement

**30 jours avant l'échéance :**
- [ ] Résultats du client révisés
- [ ] ROI calculé et documenté
- [ ] Signaux de churn vérifiés
- [ ] Opportunités d'upsell identifiées
- [ ] Proposition de renouvellement préparée
- [ ] Appel fixé
- [ ] Contrat prêt
- [ ] Plan B s'ils ne renouvellent pas

## 63.10 Checklist Journalière du Vendeur

**Chaque jour :**
- [ ] 50+ appels faits
- [ ] 10+ follow-ups faits
- [ ] 2+ rendez-vous fixés
- [ ] CRM mis à jour à 100%
- [ ] 1+ démo conduite (si applicable)
- [ ] Pipeline review faite
- [ ] 1 chose apprise aujourd'hui
- [ ] Planification de demain faite
- [ ] Énergie gérée (pauses, hydratation)

---

## Résumé du Chapitre

Checklists essentielles :
- **Pré-appel** : Préparation, recherche, objectif
- **Pendant** : Script, écoute, fermeture
- **Post-appel** : CRM, follow-up, auto-évaluation
- **Cold call** : Timing, personnalisation, gestion de refus
- **Démo** : Personnalisation, backup, fermeture
- **Follow-up** : Rapidité, valeur, date spécifique
- **Pipeline** : Prochain pas, dates, coverage
- **Onboarding** : Bienvenue, quick win, plan
- **Renouvellement** : Résultats, ROI, proposition
- **Journalière** : Volume, CRM, apprentissage
