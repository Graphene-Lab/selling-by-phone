# Capitolo 63: Checklist per la Vendita Telefonica

## 63.1 Checklist Pre-Chiamata

**Prima di ogni chiamata (5 minuti):**
- [ ] Rivedi il record CRM del prospect
- [ ] Controlla email recenti (risposte, contesto)
- [ ] Ricerca veloce su LinkedIn/azienda (se nuovo)
- [ ] Identifica il tuo obiettivo (North Star)
- [ ] Prepara 3 domande chiave
- [ ] Prepara la chiusura (prossimo passo)
- [ ] Controlla ambiente (silenzio, auricolari, connessione)
- [ ] Respira, sorridi, energia alta
- [ ] Tieni AgentBridge aperto per note
- [ ] Timer impostato (se necessario)

## 63.2 Checklist Durante la Chiamata

**Durante ogni chiamata:**
- [ ] Apertura con pattern interrupt
- [ ] Nome completo + azienda
- [ ] Motivo specifico della chiamata
- [ ] Permesso di procedere
- [ ] Domande di scoperta (aperte)
- [ ] Ascolto attivo (silenzio, parafrasi)
- [ ] Prendere appunti (AgentBridge)
- [ ] Collegare valore al loro problema
- [ ] Gestire obiezioni (LAER)
- [ ] Chiudere con prossimo passo specifico
- [ ] Confermare data/ora
- [ ] Ringraziare

## 63.3 Checklist Post-Chiamata

**Entro 1 ora dalla chiamata:**
- [ ] Aggiornare CRM con note dettagliate
- [ ] Inviare email di follow-up (se concordato)
- [ ] Pianificare prossimo passo in calendario
- [ ] Aggiornare pipeline/fase
- [ ] Documentare obiezioni sollevate
- [ ] Salvare citazioni esatte
- [ ] Auto-valutazione (cosa ha funzionato, cosa no)
- [ ] Se appuntamento fissato: inviare conferma + reminder

## 63.4 Checklist Cold Call

**Specifico per cold call:**
- [ ] Lista verificata (numero valido)
- [ ] Timing giusto (9-11 o 14-16)
- [ ] Ricerca pre-call fatta (almeno 2 min)
- [ ] Apertura personalizzata preparata
- [ ] Motivo specifico identificato
- [ ] Obiettivo chiaro (appuntamento, non vendita)
- [ ] Script di gestione rifiuto pronto
- [ ] Voicemail script pronto (se non rispondono)
- [ ] Follow-up pianificato (se non converte)

## 63.5 Checklist Demo Telefonica

**Per una demo efficace:**
- [ ] Demo personalizzata preparata (con loro dati)
- [ ] AgentBridge testato e funzionante
- [ ] Backup pronto (screenshot, video)
- [ ] Agenda inviata 24h prima
- [ ] Partecipanti confermati
- [ ] Durata definita (15-30 min)
- [ ] 3 punti chiave preparati
- [ ] Domande di check-in pianificate
- [ ] Chiusura preparata (prossimo passo)
- [ ] Materiali pronti da inviare post-demo

## 63.6 Checklist Follow-Up

**Per follow-up efficace:**
- [ ] Entro 24 ore dalla chiamata precedente
- [ ] Valore aggiunto (non solo "volevo verificare")
- [ ] Riferimento a conversazione precedente
- [ ] Prossimo passo chiaro
- [ ] Data/ora specifica proposta
- [ ] Email di supporto inviata
- [ ] CRM aggiornato
- [ ] Se no risposta: pianificare 2° e 3° follow-up

## 63.7 Checklist Pipeline Review

**Settimanale:**
- [ ] Ogni deal ha un prossimo passo
- [ ] Ogni deal ha una data di chiusura
- [ ] Nessun deal stantio (>30 giorni senza movimento)
- [ ] Pipeline coverage >3x target
- [ ] Forecast aggiornato
- [ ] Deal a rischio identificati
- [ ] Priorità settimana definite
- [ ] Supporto necessario identificato

## 63.8 Checklist Onboarding Cliente

**Prima chiamata post-vendita:**
- [ ] Benvenuto caloroso
- [ ] Obiettivi del cliente chiariti
- [ ] Setup guidato (passo per passo)
- [ ] Quick win ottenuto
- [ ] Contatti di supporto chiari
- [ ] Piano prime 4 settimane
- [ ] Prossimo check-in fissato
- [ ] Materiali di supporto inviati
- [ ] NPS iniziale raccolto

## 63.9 Checklist Rinnovo

**30 giorni prima della scadenza:**
- [ ] Risultati del cliente revisionati
- [ ] ROI calcolato e documentato
- [ ] Segnali di churn verificati
- [ ] Opportunità di upsell identificate
- [ ] Proposta di rinnovo preparata
- [ ] Chiamata fissata
- [ ] Contratto pronto
- [ ] Piano B se non rinnovano

## 63.10 Checklist Giornaliera del Venditore

**Ogni giorno:**
- [ ] 50+ chiamate fatte
- [ ] 10+ follow-up fatti
- [ ] 2+ appuntamenti fissati
- [ ] CRM aggiornato al 100%
- [ ] 1+ demo condotta (se applicabile)
- [ ] Pipeline review fatta
- [ ] 1 cosa imparata oggi
- [ ] Pianificazione domani fatta
- [ ] Energia gestita (pause, idratazione)

---

## Riepilogo del Capitolo

Checklist essenziali:
- **Pre-chiamata**: Preparazione, ricerca, obiettivo
- **Durante**: Script, ascolto, chiusura
- **Post-chiamata**: CRM, follow-up, auto-valutazione
- **Cold call**: Timing, personalizzazione, gestione rifiuto
- **Demo**: Personalizzazione, backup, chiusura
- **Follow-up**: Tempestività, valore, data specifica
- **Pipeline**: Prossimo passo, date, coverage
- **Onboarding**: Benvenuto, quick win, piano
- **Rinnovo**: Risultati, ROI, proposta
- **Giornaliera**: Volume, CRM, apprendimento

- [ ] Personalizzale per il tuo stile
- [ ] Condividile con il team
- [ ] Aggiornale mensilmente
